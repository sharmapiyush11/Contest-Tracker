# Contest Tracker

A competitive programming contest tracker and hackathon event dashboard.

## 🌐 Live Demo

👉 **[https://sharmapiyush11.github.io/Contest-Tracker/](https://sharmapiyush11.github.io/Contest-Tracker/)**

---

## 🚀 Features

- **Upcoming Contests**: Track competitive programming contests across platforms (LeetCode, CodeChef, GeeksforGeeks, Codeforces).
- **Weekly Schedule**: Overview of recurring weekly programming contests.
- **Contest Calendar**: Interactive calendar view for upcoming contest dates.
- **Hackathons & Events**: Explore active hackathons and coding events.
- **Dark / Light Mode**: Seamless theme toggling for custom visual preference.

## 🛠️ Tech Stack

- **HTML5 & CSS3**
- **JavaScript (ES Modules)**
- **GitHub Pages** for deployment

## 💻 Getting Started Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/sharmapiyush11/Contest-Tracker.git
   cd Contest-Tracker
   ```

2. Run the local development server:
   ```bash
   python -m http.server 5173
   ```

3. Open `http://localhost:5173` in your browser.
